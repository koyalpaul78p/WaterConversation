1. APP के बारे में

WaterConversation एक Water Conservation ऐप है।
इसका उद्देश्य लोगों को पानी बचाने और पर्यावरण
की सुरक्षा के लिए जागरूक करना है।

2. APP के FEATURES

- Home Dashboard
- Daily Water Usage
- Daily Water Saving Goal
- Water Saving Streak
- Daily Water Saving Tips
- Rainwater Harvesting Information
- Rainwater Calculator
- Daily Water Usage Calculator
- Water Saving Calculator
- Water Conservation Quiz
- Easy, Medium और Hard Levels
- Quiz Score और Accuracy
- My High Scores
- My Profile
- Hindi, English और Hinglish Language Options

4. GITHUB पर UPLOAD कैसे करें

1. GitHub पर अपना Repository खोलें।
2. Add file पर क्लिक करें।
3. Create new file चुनें।
4. File का नाम लिखें।
5. संबंधित Code या Text Paste करें।
6. Commit changes पर क्लिक करें।

सभी Files को एक ही Main Folder में रखें।

5. RENDER पर WEBSITE कैसे बनाएं

1. https://render.com खोलें।
2. GitHub से Login करें।
3. New पर क्लिक करें।
4. Static Site चुनें।
5. अपना WaterConversation Repository चुनें।
6. Build Command खाली छोड़ें।
7. Publish Directory में . लिखें।
8. Create Static Site पर क्लिक करें।

Deployment पूरा होने के बाद वेबसाइट का URL मिलेगा।

6. DATA STORAGE

ऐप का डेटा उसी फोन के Browser में Local Storage
के माध्यम से सेव होता है।

इसमें ये डेटा सेव हो सकता है:

- Profile Details
- Water Usage History
- Daily Goals
- Quiz Scores
- Streaks
- Language Preference

ध्यान दें:
Browser या App का Data Clear करने पर सेव किया
गया डेटा मिट सकता है।

7. IMPORTANT NOTES

- वेबसाइट चलाने के लिए Internet की जरूरत होगी।
- Service Worker HTTPS पर काम करता है।
- Google Login अभी सक्रिय नहीं है।
- Leaderboard केवल उसी डिवाइस पर सेव किए गए
  Scores दिखाता है।
